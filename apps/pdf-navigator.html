PDF Navigator

A tool for anyone whose books, manuals and documents are turning into a large library. Catalogue PDFs, search by title or content, and inspect file details.

Your PDF library in one place

PDF Navigator helps you organize, search and manage PDF documents stored in different folders.

  • Scanning selected folders and creating a document catalogue
  • Searching by document title and text content
  • Viewing covers, metadata and document contents
  • Opening files, renaming documents and editing PDF properties

Program interface

Currently available in Russian. Additional interface languages are planned.

Technical information

  • Version 1.0
  • Portable ZIP archive
  • Python is not required
  • Interface: Russian. Other languages are planned.

System requirements

  • Windows 10 / 11 (64-bit)
  • RAM: 4 GB or more

Download PDF Navigator

Get PDF Navigator as a portable ZIP archive. No separate installation or Python setup is required.

  1. Download the ZIP archive.
  2. Extract it into any folder on your computer.
  3. Run PDF_Navigator.exe.

Your catalogue, settings and other program data will be stored inside the program folder.
